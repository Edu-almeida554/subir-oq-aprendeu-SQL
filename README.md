# Resumo de Comandos SQL

Notas de estudo organizadas sobre os principais tipos de comandos SQL: **DDL**, **DQL** e **DML**.

## 📚 Conteúdo

- **DDL (Data Definition Language)** — comandos para definir e modificar a estrutura do banco de dados (`CREATE`, `ALTER`, `DROP`).
- **DQL (Data Query Language)** — comandos para consultar dados (`SELECT`, `WHERE`, `ORDER BY`, `DISTINCT`, entre outros).
- **DML (Data Manipulation Language)** — comandos para manipular os dados dentro das tabelas (`INSERT`, `UPDATE`, `DELETE`).
